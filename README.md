# Blog Uploader · Obsidian 一键上博插件

配合 [obsidian-blog（数字花园）](https://github.com/lunshi2022/obsidian-blog) 使用：写完笔记点一下，自动完成

> 复制笔记到博客仓库（保持库内目录结构）→ 复制它引用的全部附件 → 自动构建（可选）→ git 提交推送（可选）

纯 JavaScript、零依赖、仅桌面版 Obsidian。

## 安装

1. 把本仓库的 `main.js` 和 `manifest.json` 复制到你的 Obsidian 库：

   ```
   <你的库>/.obsidian/plugins/blog-uploader/
   ```

2. Obsidian 设置 → 第三方插件 → 关闭安全模式 → 启用 **Blog Uploader**
3. 打开插件设置，填入**博客仓库根目录**（部署器部署好的那个目录）

## 用法

- 左侧边栏的 ↑ 图标，或命令面板「上传当前笔记到博客」
- 文件列表里右键任意笔记 → 「上传到博客」
- 命令面板 → 「本地预览（构建并打开浏览器）」/「停止本地预览服务」：不用开终端就能看效果（需要本机装 Node.js；没装不影响发布，由 GitHub 云端构建）
- 「修改后再上传一次」就是更新（同名覆盖）；不想发布的笔记写 `draft: true`
- 设置里可分别开关「自动构建」和「自动推送」，想攒一批再发就关掉推送

## 推送与认证

- 推送需要本机装有 **git**
- 推荐在插件设置里填入 **GitHub 访问令牌（PAT）**：推送时令牌内嵌进远程 URL，完全绕开 Git Credential Manager 的交互弹窗（否则可能卡在「选择账户」页面）
- 令牌保存在插件配置里，**永不上传**（`.obsidian/` 已被博客仓库的 .gitignore 排除）

## 常见问题

- **推送失败提示 `GH013`**：说明推送内容里被检测到令牌/密钥。检查博客仓库的 `.gitignore` 是否排除了整个 `.obsidian/`
- **提示「内容没有变化」但仍想推送**：插件会在有积压提交时照常推送，只有本地远端完全一致时才提示无需推送
- **改了设置不生效**：更新 main.js 后需要重载插件（设置里关闭再开启，或重启 Obsidian）
